# Store listing: AMOLED Pure Black Theme – Totality

**Package:** `dist/amoled-pure-black-theme-totality-1.0.0.zip` (build with `tools/package.sh`)

## Where to publish: the Chrome Web Store
Microsoft Edge Add-ons doesn't accept third-party themes. The Microsoft Edge team said so in their own GitHub repo ([discussion #96](https://github.com/microsoft/MicrosoftEdge-Extensions/discussions/96), 2023), and I found nothing since that changes it. Publish the theme on the **Chrome Web Store** instead (https://chrome.google.com/webstore/devconsole, one-time $5 developer fee). Edge users can install from there after turning on "Allow extensions from other stores", which Edge offers automatically when they visit the listing.

If Partner Center does offer a theme option when you upload, try it too: the same zip works.

## Description
```
Totality is a true-black browser theme made for OLED and AMOLED screens.

On an OLED display, black pixels are switched off. Totality keeps the whole browser frame at pure #000: the tab strip, vertical tabs, toolbar and address bar. That saves power and gives you perfect contrast. Text is a warm, soft white instead of harsh grey, so it reads more like paper under lamplight than a terminal.

The new tab page shows a total solar eclipse: a black moon, a streaming corona, a small pink prominence on the rim and the flash of the diamond ring. More than 95% of its pixels are pure black. Hide the news feed in the new tab page settings to see the whole sky.

• Pure black (#000) tabs, toolbar and window frame
• Warm corona-white text, easy on the eyes at night
• Works with vertical tabs and horizontal tabs
• Original eclipse artwork on the new tab page
• Made for OLED / AMOLED laptops and monitors, and just as good on any dark setup

Tip: for menus and settings pages to match, set your browser's appearance to Dark.

The theme contains no code and collects no data.
```
